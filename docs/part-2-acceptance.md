# 第二部分：文件校验与预览

## 入口与阶段边界

打开项目详情，点击「上传并预览」。未登录时也可进入明确标注的界面预览，
选择示例项目后体验此流程。这里只读取用户主动选择的本地文件，不查询历史内容、不上传原始文件、
不创建 import_batches、不写业务表，也不请求额外数据库或 Storage 权限。

文件、字段映射、报告和文件 SHA-256 仅留在当前页面内存。刷新、退出项目或关闭页面后清除。
不修改原始文件。正式入库、原始层留存、历史记录和跨批次去重是第三部分的范围。

## 支持的文件

- 一次选择 1 个 `.xlsx` 工作簿，或最多 3 个 `.csv` 文件，不混合两种格式。
- 一批文件合计不超过 20 MiB、10,000 条非空记录；最多 64 列，单个文本单元格不超过 10,000 字符。
- Excel 最多 8 张表；预先检查压缩目录，拒绝加密、宏、ZIP64 及声明解压体积过大的容器。
- 暂不支持 `.xls`、`.xlsm`、压缩包或平台 API 自动同步。
- CSV 支持 UTF-8/BOM、GB18030/GBK、逗号/分号/制表符、引号及多行文本。
- 第一行必须是表头。空或重复表头、数据超出表头列数、CSV 引号不完整均明确报错。

## 数据结构与映射

建议使用 Posts、Metrics、Comments；也支持「内容」「指标」「评论」等常见表名。
自动识别不到的表默认忽略，用户可手动指定类型；Accounts / Data_Dictionary 等辅助表不自动当业务数据。
每个类型只允许一个来源表，冲突会报告为整表错误，所有记录仍可查看。

Posts 必须提供，且有内容记录。本阶段允许先预览 Posts，未提供 Metrics / Comments 时明确提示覆盖不完整；
完整导入工作簿仍建议包含三张表，空数据表保留表头。这是对 V1.0 标准模板的阶段性预览兼容规则。
Metrics / Comments 的内容编号必须在本批 Posts 中找到，本阶段不把数据库历史记录当作已核验来源。

标准字段可自动匹配常见中英文字段。用户可更改源列，必填字段缺失或源列重复映射会报错。
未映射列不进入标准化预览，原始文件保持不变。

## 数据规则

- 空白归为 NULL，观测到的 0 保留为 0；不将平台 -1 等特殊码擅自当成缺失。
- 计数以十进制文本保存于预览模型，完整保留 PostgreSQL BIGINT 范围，不使用 JS 浮点数承载大整数。
- 长编号如已在 Excel 中失去数值精度，则报错要求以文本提供；可识别的纯零补位格式保留前导零。
- 时间支持 `YYYY-MM-DD HH:mm:ss` 或带偏移的 ISO 时间。未注明偏移时，按内容行 timezone 或项目默认时区处理。
- 不猜测秒/毫秒时间戳；非法日期与夏令时重复/缺失时刻报错，需显式偏移消除歧义。
- Excel 日期支持 1900/1904 日期系统，按墙上时间处理，再转换为项目时区对应的 UTC。
- 公式、数组公式及 Excel 错误单元格不使用缓存结果代替观测，映射到业务字段时报错。
- 项目内内容键唯一；快照键为内容、UTC 时间、类型和口径；当前只接受 cumulative。
- 相同内容的稳定平台评论 ID、同批文件评论键重复属于错误；推断的相同评论文本只提示并保留。
- 评论/快照早于内容发布时间属于待核对提示，不直接删除。
- 指标字段名匹配不等于指标口径获确认。缺少口径时使用明确的 `pending_review` 标记，不开展跨平台统计。
- 来源许可证、公开展示授权和模型结果均不由结构校验推断。

## 质量报告

显示总记录、无错误记录、错误记录、重复/疑似重复记录、数据类型、字段覆盖率、
来源表和问题处理建议。重复数是前述记录的子集，不能与错误或通过数相加。
有效记录率 = 无错误的记录数 ÷ 总输入记录数；整表级错误单独显示，提示不会被算作错误。

Excel 记录号对应工作表行号；CSV 记录号包含表头和空白记录，是 CSV 逻辑记录号，
带换行的引号文本不会被当成多条记录，因此不等同于文本编辑器的物理行号。

可下载 UTF-8/BOM 问题清单。报告中的公式样式字符串加保护前缀，避免用 Excel 打开时执行公式。
下载内容不含整段原始评论，但可能含文件名和字段信息，应按自己的数据权限保存。

## 验收步骤与证据

1. 使用「先用合成示例试一下」，识别三张表、核对自动映射并运行校验：6 条记录，无核心错误。
2. 查看 Metrics，确认空值为「未提供」、明确的点赞数为 0。
3. 返回映射，取消 title，报告应定位整表必填映射错误和对应记录错误。
4. 载入「含错误的示例」，确认重复内容键、负数及不存在的内容关联均被报告。
5. 上传自己的标准 Excel/CSV，核对来源记录号、字段映射、覆盖率和文件哈希。
6. 下载问题清单；刷新页面应回到文件选择，不保留前一批文件。
7. 「确认入库」保持禁用，数据库不会因为本流程出现新业务数据。

已验证：57 项自动测试、类型检查、实际 Excel 文件选择、三类 CSV 自动映射、缺失值/0 展示、
手动取消必填映射的错误报告、CSV 下载及手机宽度下整页不横向溢出。
大表采用分页预览，宽字段表在自身容器内横向滚动。
