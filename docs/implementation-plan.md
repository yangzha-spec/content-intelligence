# 开发阶段与验收

## 阶段 0：仓库与数据模型

- [x] 保存原始数据字典，补充数据库设计决策。
- [x] 准备 P0 的 8 张业务表及 RLS。
- [x] 提供数据库自动验证，不依赖真实数据或云端凭据。
- [ ] 创建 Supabase 项目、执行迁移并通过云端权限验证。

## 阶段 1：最小导入闭环（P0）

沿用需求稿的 Next.js + TypeScript、Supabase 方向；应用脚手架与依赖版本将在该阶段确定。
先支持标准 Posts / Metrics / Comments 工作簿；CSV 使用三类文件并共享一个导入批次，上传协议需在实现时明确。
跨平台自动适配与外部数据集接入不作为本阶段前置条件。

- [ ] 登录、工作空间初始化、创建项目。
- [ ] 原始文件私有存储，文件内容/类型/大小限制。
- [ ] CSV/XLSX 解析、字段映射、预览。
- [ ] 必填值、重复键、时间、负数、NULL、内容关联校验。
- [ ] 行级错误报告与批次质量汇总；解析后的临时数据可重建。
- [ ] 一次确认在一个事务内写入三类数据；锁定批次，重复提交不重复写入。
- [ ] 导入历史、来源批次、文件哈希、映射/处理版本可追溯。

验收：合成样本完整导入；错误行可定位；NULL 与 0 保持区别；
同批次重复提交和失败重试不重复写入；另一个工作空间无权访问原始文件及业务数据。

## 阶段 2：确定性统计（P1）

- [ ] 增加 `analysis_runs`、`analysis_results` 迁移。
- [ ] 明确累计快照选取：在截止时间前按内容、口径取最新可用快照，不能累加历史累计快照。
- [ ] 显示内容量、有效指标总和、均值、中位数、排名和时间趋势。
- [ ] 显示指标定义、有效样本量、缺失率、筛选条件和时间范围。
- [ ] 记录输入批次、数据范围、数据/代码/指标口径版本。

验收：使用可人工核对的小样本验证统计；全缺失字段返回不可计算；
不同平台口径不直接混合；发布趋势与累计快照增长分别标明。

## 阶段 3：评论分析（P2）

- [ ] 增加 `comment_analyses`，记录任务、模型版本、失败和未知状态。
- [ ] 选择模型并以可信样本评估，再实现情感、关键词与主题分析。
- [ ] 对抽样评论说明覆盖限制；先抽样人工复核，再决定是否上线方面级分析。
- [ ] 方面级功能验证通过后增加 `comment_aspects`。

## 阶段 4：AI 洞察与报告（P3/P4）

- [ ] 增加 `insights`、`reports`。
- [ ] LLM 只解释分析引擎输出的统计结果，每条洞察包含证据、样本量与限制。
- [ ] 报告私有存储、权限下载与项目删除时的文件清理。
- [ ] 完成部署、演示数据标识与使用说明。

## 待决定事项

云端项目地区、真实数据集授权、平台指标定义、评论模型与 LLM 服务商、
是否独立 Python 服务、数据保留期限和报告导出方案仍待对应阶段确认。
