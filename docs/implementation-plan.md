## 阶段 1：最小导入闭环（P0）

已采用 Next.js 16、React 19、TypeScript 和 Supabase 浏览器客户端，依赖固定版本并提交锁定文件。
此阶段分为三次交付：登录与项目管理、导入预览、确认入库，各自独立验收。
先支持标准 Posts / Metrics / Comments 工作簿；CSV 使用三类文件并共享一个导入批次，上传协议需在实现时明确。
跨平台自动适配与外部数据集接入不作为本阶段前置条件。

- [x] 登录、工作空间初始化、创建项目的应用实现。
- [ ] 真实账号的邮箱确认、项目创建与重登保留验收。
- [x] 原始文件私有存储，文件内容/类型/大小限制。
- [x] CSV/XLSX 本地解析、字段映射、预览。
- [x] 必填值、重复键、时间、负数、NULL、内容关联校验。
- [x] 记录级错误报告与批次质量汇总；临时数据可重新解析，不上传或写库。
- [x] 一次确认在一个事务内写入三类数据；锁定项目与批次，重复提交不重复写入。
- [x] 导入历史、来源批次、文件哈希、映射/处理版本可追溯。
- [ ] 真实账号下 Storage → Edge → 入库与下载的完整验收（见第三部分说明）。

验收：合成样本完整导入；错误行可定位；NULL 与 0 保持区别；
同批次重复提交和失败重试不重复写入；另一个工作空间无权访问原始文件及业务数据。

## 2026-11-04 开发安排

按用户要求，注册登录与真实账号端到端验收统一留到最终阶段，不作为演示和后续开发前置条件。
V0.5 已提供内容统计、评论规则初筛、证据建议、报告导出、分析历史，以及五组复杂合成数据操作图。
所有未勾选事项保留为真实接入、模型评估或后续功能，不将演示或模拟测试当作实测完成。

V0.6 已补上手动原文件清理：默认持续保留，仅空间所有者逐批确认；清理记录不可回退，期间禁止补传和入库。真实文件清理仍待最终账号验收，没有执行定时自动删除。

V0.7 已增加仅在浏览器运行的人工复核与评估工具。教学标注明确标识为合成演练；没有把自动测试或演示分数当作正式模型效果。标注需下载 JSON 保存，尚未写入数据库或纳入历史分析报告。

V0.8 已增加 AI 调用限制与恢复，默认不启用模型。新增两张私有控制表及有限授权的全局计数接口，业务保存仍使用用户会话；每日 5 次/人、20 次/应用，同时 1 个有效预约。实际付费及跨实例并发 HTTP 验收仍留到最终接入。

V0.9 已提供复核私有草稿与演示本机保存，不需注册即可体验演示恢复。云端仅作者本人可读写，版本校验保护旧页面提交；当前仅保留每个范围的最新草稿，不是多人协作或历史版本库。人工标注仍不写入已保存分析报告。
