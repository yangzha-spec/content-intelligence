# 第六部分：评论人工复核与评估工具

## 操作体验

打开演示项目的「评论洞察」，点击「进入人工复核与评估」。可以先选评论标注，也可点击「载入教学标注」体验明确标识的合成演练。

- 逐条选择正向、负向、中性或人工无法判断；填写标注者和备注。
- 主题允许多标签，未复核（null）与明确无主题（空集合）分开。
- 队列支持原文搜索、未标注、规则未判断、人工不一致及按编号固定取样 60 条；队列筛选不改变已保存标注的评估分母。
- 查看含规则拒判列的混淆矩阵、各类 Precision/Recall/F1、覆盖率、含拒判一致率、已判断子集一致率及主题评估。
- 导出 JSON 用于恢复，导出含原文 CSV 用于离线核对，导出评估 Markdown 用于记录方法与分母。
- 同一项目的分析模块间切换保留标注。未导出时阻止离开项目、切换空间、退出预览、重新分析或加载其他历史结果；刷新/关闭显示浏览器离开提示。

没有自动保存到云端或浏览器持久存储，刷新/关闭前须实际下载 JSON。标注不覆盖原始初筛，也不写入已保存的分析报告。当前没有多人协作标注或身份认证。

## 匹配和文件校验

复核集 SHA-256 覆盖项目、输入版本、完整筛选、评论编号/原文/归属/采样、规则标签/主题和方法；行顺序不影响指纹。
JSON 严格匹配当前范围，数量、重复编号、非法标签、未授权主题、超长备注和非法时间等整份拒绝。合并遇到同一评论内容冲突也整份拒绝，不用时间戳自动覆盖。
文件上限 16 MiB。实际项目不接受教学示例来源标记。作者名称没有身份核验，指纹不是作者签名。
JSON 不自动附带评论正文，但备注可能含自填引用；CSV 包含原文并中和公式前缀。请自行保管导出文件。

## 验证

2026-11-04 自动测试共 114 项通过。新增 12 项验证手算混淆矩阵/指标、拒判分母、主题空集合、范围指纹、文件恢复/冲突、非法记录、固定取样和 CSV 注入防护。
浏览器已验证人工编辑保存、跨模块保留、未导出离开/重算保护、JSON 实际下载和载入、范围不匹配与标注冲突的完整拒绝。正式构建和类型检查通过。390 像素视口下页面内容宽度与滚动宽度一致（375），宽表仅在自身容器滚动。
实际导出 CSV 为 2,388 条数据、12 列，其中 12 条有人工标签；Markdown 包含类别指标和合成演练边界。相同输入重新分析后已导出的标注仍保留。

截图中全平台评论筛选后为 2,388 条；教学示例有 12 个不同文本，对应真实 UI 操作和实际评估计算，不代表 2,388 条已经人工标注。验收中只改动了一条合成示例的说明，其他仍明确标记为教学来源。

## 本部分边界

本部分只补齐复核与评估工具。真实授权样本、独立可信标注集、正式 NLP 模型选择/推理/效果、双人一致性、方面级情感仍未完成；不得将教学指标当作真实模型效果。
未新增数据库表、权限、服务密钥或付费调用；用户的最终注册登录与真实 Storage/保存验收仍按原计划留到最后。

标注与公式详见 [标注指南](comment-annotation-guide.md)。
