# 评论标注指南 V1

本指南统一局部复核的操作，不代表已经建立可信模型测试集。

## 先明确范围

固定项目、平台、日期和主题，下载并保留原始数据的来源/授权。复核集指纹包含项目、输入源、筛选、原文、初筛标签和方法。
正式评估应预先定义标签、样本获取、训练/验证/测试隔离及争议裁决，再开始标注。不要按当前模型错误反复调整测试集。
本页的「固定取样 60 条」按评论编号排序等距取样，不是随机或分层抽样；「规则未判断」和「人工与规则不一致」队列会选择特定样本，不能据此推断总体效果。

## 情感标签

| 标签 | 操作定义 | 教学示例 |
| --- | --- | --- |
| 正向 | 对内容、产品或互动表达明确肯定 | 教程很实用，步骤清晰。 |
| 负向 | 对相关对象表达明确不满或否定 | 看不懂具体操作，演示不清楚。 |
| 中性 | 语境中无明确正负倾向，且能判断为中性 | 收到。 |
| 人工无法判断 | 需要上下文、混合正负或含义不明确，无法可靠给一个整体极性 | 喜欢这个系列，但是价格太贵。 |

未标注不是人工无法判断。不要为了补满数量，把未读评论归为中性；也不要直接复制词典输出作为人工真值。
默认隐藏规则结果只是减少提示，不构成严格盲测，因为分析页其他位置仍可见初筛、主题和命中词。

## 多标签主题

五个候选主题为内容质量、教程需求、产品体验、价格与成本、发布与互动。
可以选择多个主题。明确读过并确认没有相关主题时，勾选「本条主题已复核」并全不选；暂未检查主题时不要勾选。
情感无法判断不妨碍主题明确，例如混合情感仍可明确涉及价格和互动。

## 保存与恢复

1. 填写自用标注者名称，选择人工情感、主题与备注，点击保存本条标注。备注最多 240 字，避免录入多余个人信息。
2. 标注暂存本页，刷新/关闭前下载 JSON 并确认文件保存在本机。页面不会自动存入数据库、浏览器持久存储或外部 AI。
3. 后续打开相同输入和筛选，载入 JSON 继续。文件与当前范围不匹配时整份拒绝；与已存在标注冲突时整份拒绝，不静默覆盖。
4. 更新一条已有标注须在编辑面板保存，或撤销上次保存/导入。更新后重新导出 JSON。

JSON 包含编号、标签、备注、自填标注者、时间和复核集指纹，不自动附带评论正文；备注仍可能包含自行抄录的原文。CSV 明确包含原文，请按实际数据授权和团队要求保管。
标注者与时间是用户自填/客户端记录，没有认证签名，SHA-256 仅核对数据匹配。不同标注者的冲突不会自动裁决。

## 解释评估

情感分母仅为已标注且人工可判断的评论。规则未判断参与该分母，计为漏判；人工无法判断单独计数，不视为中性。
与人工一致率 = 一致条数 / 人工可判断条数；覆盖率 = 规则已判断条数 / 人工可判断条数；已判断样本一致率仅以规则已判断部分为分母。必须同时报告覆盖率，不能只报较高的后者。
类别 Precision = TP/(TP+FP)，Recall = TP/(TP+FN)，F1 = 2TP/(2TP+FP+FN)。宏平均只对有人工支持样本的类别平均，并显示覆盖几类；无样本或零分母显示不可计算。
主题评估只使用明确复核主题的评论，统计集合完全一致率及微平均 Precision/Recall/F1。全不选的空集合参与完全一致率；没有任何正标签时微平均 F1 不可计算。

公式定义参考 [scikit-learn 分类指标文档](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics)。本工具为规则拒判和未覆盖类别明确采用上述分母，不宣称与某个库的默认选项完全等价。

## 正式模型评估尚需完成

真实授权评论、清晰采样设计、独立人工标注、双人一致性检查及争议裁决、固定测试集、模型版本与实际推理、类别/语言/采样覆盖和错误分析。
内置教学标注为开发者写的语义演示，不是独立标注的真实数据，不能用于简历或报告中的模型效果声明。
